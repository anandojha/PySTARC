# Hirudin C-tail / thrombin (protein-peptide chain BD)

## System

| Property                    | Value                                                    |
|-----------------------------|----------------------------------------------------------|
| Receptor                    | Thrombin exosite I (rigid target)                        |
| Ligand                      | Hirudin C-terminal tail (residues 53-65)                 |
| Chain sequence              | ASN-GLY-ASP-PHE-GLU-GLU-ILE-PRO-GLU-GLU-TYR-LEU-GLN      |
| Caps                        | ACE (N-term), NME (C-term)                               |
| Chain atoms                 | 38 (coarse-grained, COFFDROP)                            |
| Chain net charge            | -5 e                                                     |
| Crystal structure           | 1PPB                                                     |
| b-surface                   | 50.0 Angstrom                                            |
| Escape sphere               | 80.0 Angstrom                                            |
| Reaction n_needed           | 3 contact pairs                                          |
| Born desolvation            | enabled                                                  |
| Soft repulsion (WCA)        | enabled                                                  |
| Diffusion mode              | auto (RPY tensors from geometry)                         |
| Outer dt                    | 0.2 ps (rigid-body translation/rotation)                 |
| Inner dt                    | 0.025 ps (chain internal coordinates)                    |
| Equilibration steps         | 0 (default; production: 4000 = 100 ps at dt_chain=0.025) |
| Trajectories (default)      | 1000 (production: 10000+)                                |
| Experimental k<sub>on</sub> | 2.9 x 10<sup>8</sup> M<sup>-1</sup>s<sup>-1</sup>        |

## Input files (provided in this directory)

| File                       | Description                                                                          |
|----------------------------|--------------------------------------------------------------------------------------|
| `1PPB.pdb`                 | Crystal structure of the thrombin-hirudin complex.                                   |
| `thrombin.pdb`             | Thrombin extracted from 1PPB.                                                        |
| `thrombin.pqr`             | Thrombin PQR (charges + radii).                                                      |
| `hirudin_ctail.pdb`        | Hirudin C-tail extracted from 1PPB.                                                  |
| `hirudin_ctail.pqr`        | Hirudin C-tail PQR (reference; chain is built from sequence by `setup.py`).          |
| `reaction_pairs.json`      | Reaction contact triples: `[target_atom_idx, chain_atom_idx, distance_A]`.           |
| `setup.py`                 | Generates `chain.json` (chain topology) and `input.xml` (BD configuration).          |
| `run.sh`                   | Runs setup and chain BD simulation in one command.                                   |

## Prerequisite: APBS DX grids

Chain BD requires pre-computed APBS electrostatic and Born desolvation grids in `apbs_output/`.
These are **not** generated by `setup.py` and must be placed in `apbs_output/` before launching.

| File                              | Description                            |
|-----------------------------------|----------------------------------------|
| `apbs_output/thrombin1.dx`        | Electrostatic potential (fine grid)    |
| `apbs_output/thrombin1_born.dx`   | Born desolvation potential (fine grid) |

Copy from the archive (one-time):
```bash
mkdir -p apbs_output
cp /mnt/home/aojha/Downloads/pystarc_backups/PySTARC_v2_results_archive/hirudin_thrombin/apbs_output/thrombin1.dx apbs_output/
cp /mnt/home/aojha/Downloads/pystarc_backups/PySTARC_v2_results_archive/hirudin_thrombin/apbs_output/thrombin1_born.dx apbs_output/
```

## What setup.py generates

| Generated file   | Description                                                                              |
|------------------|------------------------------------------------------------------------------------------|
| `chain.json`     | Chain topology (atoms, bonds, angles, torsions) + initial body-frame positions.          |
| `input.xml`      | PySTARC input file with rigid-body parameters and the chain BD `<chain>` block.          |

## Setup and run
```bash
conda activate PySTARC
cd examples/hirudin_thrombin
# One-time: place DX grids (see "Prerequisite" above)
python setup.py
python ../../run_pystarc.py input.xml
```

Or in one command (after DX grids are placed):
```bash
conda activate PySTARC
cd examples/hirudin_thrombin
bash run.sh
```

## Output files

After simulation completes, results are written to `bd_sims/`. Eleven of fourteen
OutputConfig flags are implemented in chain BD mode (the remaining three are
accept-but-skip silently — see Notes below).

| Output file              | Description                                                                                                              |
|--------------------------|--------------------------------------------------------------------------------------------------------------------------|
| `results.json`           | k<sub>on</sub>, P<sub>rxn</sub>, Wilson 95% CI, k<sub>b</sub>, wall time, chain summary, BD parameters.                  |
| `trajectories.csv`       | Per-trajectory record: steps, fate, time, final separation, reaction name.                                               |
| `encounters.csv`         | Binding encounter poses for reacted trajectories: position + orientation at reaction.                                    |
| `near_misses.csv`        | Closest-approach record for non-reacted trajectories.                                                                    |
| `paths.npz`              | Per-snapshot COM + orientation + radial trace (full chain trajectory paths).                                             |
| `radial_density.csv`     | Radial probability density as a function of distance from the receptor.                                                  |
| `angular_map.npz`        | 2D angular occupancy heatmap (theta, phi).                                                                               |
| `fpt_distribution.csv`   | First-passage times for reacted trajectories.                                                                            |
| `contact_frequency.csv`  | Per-pair contact frequencies for the reaction criterion atom pairs.                                                      |
| `milestone_flux.csv`     | Outward / inward flux across radial shells.                                                                              |
| `energetics.npz`         | Per-snapshot energy decomposition (electrostatic, Born) along trajectories.                                              |

A timestamped log file (`pystarc_YYYYMMDD_HHMMSS.log`) is also written to `bd_sims/`.

## Notes
- The chain is built fresh each run from the dash-separated 3-letter sequence using `chain_from_sequence` and `place_relaxed_geometry` from the COFFDROP module. The `hirudin_ctail.pqr` file is provided as a reference but is not consumed by `setup.py`.
- DX grids are not regenerated by `setup.py`; the workflow assumes pre-computed APBS output.
- Three OutputConfig flags are accepted but currently no-op in chain BD mode: `p_commit`, `transition_matrix`, `pose_clusters`. Each requires new analysis code beyond simple file emission.
