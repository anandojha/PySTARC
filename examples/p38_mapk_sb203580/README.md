## Setup and run

Pre-generated files are not included because the ligand parameterization (antechamber AM1-BCC) must be run at setup time. Run setup.py first:

```bash
conda activate PySTARC
module load cuda
cd examples/p38_mapk_sb203580
python setup.py
python ../../run_pystarc.py input.xml
```

Or in one command:

```bash
conda activate PySTARC
module load cuda
cd examples/p38_mapk_sb203580
bash run.sh
```

## Dependencies

In addition to the standard PySTARC dependencies, setup.py requires antechamber (from AmberTools, included in the PySTARC conda environment) to parameterize the ligand with GAFF2 force field and AM1-BCC partial charges.

## Reaction criterion

Four crystal-structure contacts between p38 and SB203580 define the reaction criterion:

<table width="100%">
<thead><tr><th align="left">Pair</th><th align="left">Receptor atom</th><th align="left">Ligand atom</th><th align="left">Contact type</th></tr></thead>
<tbody>
<tr><td>1</td><td>MET106 N (hinge)</td><td>NB1</td><td>Hinge H-bond</td></tr>
<tr><td>2</td><td>LYS50 NZ (catalytic)</td><td>NC3</td><td>Catalytic lysine</td></tr>
<tr><td>3</td><td>VAL102 O (backbone)</td><td>FD3</td><td>Backbone carbonyl</td></tr>
<tr><td>4</td><td>THR103 N (backbone)</td><td>FD3</td><td>Backbone amide</td></tr>
</tbody>
</table>

With `n_needed=2`, any two of the four contacts firing simultaneously counts as a reaction.

## Notes

- SB203580 is electrically neutral at physiological pH. Association is driven purely by diffusion and short-range interactions, not electrostatic steering.
- The His-tag residues (residues 1-3 in PDB 1A9U) are excluded from the receptor to avoid artifacts from the expression construct.
- The ligand is parameterized separately from the protein using antechamber (GAFF2 + AM1-BCC), then each molecule gets its own AMBER topology and PQR file.
- PQR files are generated from the AMBER topology via `cpptraj` and `ambpdb`.
- The geometry check reports that b + R<sub>max, lig</sub> = 68 Å slightly exceeds the fine grid half-extent of 64 Å. The Yukawa multipole fallback handles the overshoot for the outermost ligand atoms at the b-surface.
